The NIPOST Postcode system exposes a public API that organisations can integrate. If you build location-aware products in Nigeria, this is the moment to adopt it. It replaces the old 6-digit numeric postcode with an 11-character alphanumeric identifier tied to an addressable building. 

## How to integrate the NIPOST postcode API

1. Create an organisation developer account at the [NIPOST postcode portal](https://postcode.gov.ng/#get-app).
2. Generate an API key from the developer dashboard.
3. Pick the integration surface that fits your product:
    - **REST API** for backend services and address lookups.
    - **Web and mobile SDKs** for user-facing forms and checkout flows.
    - **Bulk access** for migrating an existing address database in one pass.

## Why migrate from the 6-digit postcode

The old 6-digit postcode is being phased out. Teams that migrate early avoid double entry, address rewrites, and compliance friction later.
