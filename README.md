# TechExpat

Agency portfolio and client portal.

## Tech Stack

- Java 25, Spring Boot 4.0.2
- Thymeleaf + Layout Dialect
- Bootstrap 5.3.8
- Gradle 9.3
- Deployed on Railway

## Running Locally

```bash
./gradlew bootRun
```

App runs at `http://localhost:8080`

## Running Tests

```bash
./gradlew test
```
